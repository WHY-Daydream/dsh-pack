# v0.6.0 — Release Invariant Review（RI-17–RI-28 冻结与反向 call-site 审计）

**Date**: 2026-08-31
**Target**: `v0.6.0` — Distributed Verifiable Evidence（alpha.1 discovery → alpha.2 publication →
alpha.3 remote evidence cache → beta.1 remote trust integration → beta.2 registry interoperability →
rc.1 adversarial distribution matrix 已全部合并）
**Base**: main `6b84a99`（Merge PR #20）
**Method**: 接在 v0.5 冻结的 RI-01–RI-16 之后，冻结 RI-17–RI-28；随后对每个 invariant 做
**反向 call-site bypass audit** —— 目标不是“这些函数都有测试吗”，而是
**“有没有第二条 call path 可以绕过这些 invariant”**。

## 冻结：RI-17–RI-28

| # | Invariant（不可违反的语义） | 对应冻结决策 |
|---|------------------------------|--------------|
| **RI-17** | OCI referrer subject identity ≠ DSH Evidence subject identity | D152/D155：`subject.manifestDigest`（OCI）与 `subject.contentHash`（DSH）是两个独立身份域，永不相混淆 |
| **RI-18** | Remote discovery locator = `(registry, repository, OCI manifestDigest)` | D157/D192：repository-scoped locator；同 digest 跨 repo 不串 Evidence |
| **RI-19** | Mutable tag 在 Evidence discovery 之前解析一次；tag 永远不成为 immutable identity | N1/D197：resolve `tag → M` 后锁定 digest，后续不跟 tag 漂移 |
| **RI-20** | Registry enumeration 是不可信输入 | D191：descriptor 数量/顺序/annotation/artifactType 都不能产生 Trust |
| **RI-21** | Complete pagination 是授权前置条件；partial enumeration 不能产生 ALLOW | D193/RC6-N1：loop/跨源/非法 next link/截断 → fail-closed |
| **RI-22** | artifactType / registry filtering / ordering 永不建立 Evidence type 或 Trust | D152/D186：Envelope.type 是唯一类型来源；order 不选 winner |
| **RI-23** | Remote carrier 恰好一个 envelope；required document 按 digest 绑定 | D159/D125：strict cardinality；document digest mismatch → reject |
| **RI-24** | Evidence attachment 不改变 Agent Image M 或 DSH contentHash C | D155/D188：publication 不改写 subject；M before == M after |
| **RI-25** | Cache 只存 bytes/snapshots，永不存 TRUSTED / ALLOW / DENY | D166–D168：content-addressed bytes cache，不是 trust cache |
| **RI-26** | Online 授权使用 current remote enumeration + current trust.yaml | D169/D176/RC6-N4：snapshot 不遮蔽远程新 Evidence；撤销立即改变 verdict |
| **RI-27** | Offline cached Evidence 在 v0.6 policy 语义下不能授权执行 | D170/D174：offline 显式 + complete snapshot only；`OFFLINE_CACHE_INCOMPLETE` fail loud |
| **RI-28** | Registry/cache/proxy/distribution 失败不能绕过 pre-materialization Trust Gate | D199/D148：所有 distribution/trust error 先于 materialization |
