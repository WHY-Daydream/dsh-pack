## CA-01 — semver compatibility regression（✅）

- `pnpm vitest run tests/peer-range.spec.ts` → **14 passed**（范围字符串精确断言 + 13 条匹配契约）。
- 契约：`0.1.0-rc.5/rc.6/rc.8`、`0.1.1-rc.1/rc.2`、`0.1.2-rc.1`、`0.1.2-alpha.5`、`0.1.3-alpha.1`、`0.1.0`、`0.1.4` → true；`0.1.0-rc.4`、`0.2.0-alpha.1`、`0.2.0` → false。
- peer range（最终）：
  `>=0.1.0-rc.5 <0.2.0-0 || >=0.1.1-0 <0.2.0-0 || >=0.1.2-0 <0.2.0-0 || >=0.1.3-0 <0.2.0-0`
- 说明：npm semver 的 prerelease 规则要求候选 prerelease 与 range 内某比较器共享 major.minor.patch 元组；
  单一 `<0.2.0-0` 上界窗口**不能**覆盖 `0.1.2-rc.1`/`0.1.3-alpha.1`（semver 7.8.4 实证 false；npm 安装实证 ERESOLVE），
  故每条已发布 / 源码内 0.1.x prerelease 行需要显式 `>=X-0` union 成员。
